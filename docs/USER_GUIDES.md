# User Guides & How-tos

This file contains short user-facing guides to help students and mentors use StudentHub.

Getting started

- Create a profile using the "Get Started" button on the homepage. Add your role and skills so others can find you.

Posting an idea

- Click "Propose" or navigate to `pages/ideas.html` and fill out the idea form. Add tags and a short description.
- After posting, your idea appears on the Ideas board where others can upvote or comment.

Joining a project

- On a project's page, click "Contribute" to open the project's GitHub issues page (or follow the internal join flow if configured).

Running or joining events

- Browse `pages/events.html` (when available) for upcoming workshops and RSVP.

Reporting problems

- Use the Bug report template in issues with steps to reproduce and environment details.
