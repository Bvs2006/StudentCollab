# Code of Conduct

This project follows the Contributor Covenant v2.0. We expect everyone to be respectful, inclusive, and professional.

Key points:
- Be kind and patient. Harassment, hate speech, or exclusionary behavior will not be tolerated.
- Assume good intent and give people the benefit of the doubt.
- When conflicts arise, escalate to project admins and aim for constructive resolution.

If you experience or witness unacceptable behavior, please contact the project maintainers.
